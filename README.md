# 2GIS Reviews Exporter

Небольшой Python-скрипт для выгрузки текстов отзывов организации из 2GIS.

Скрипт получает отзывы через API 2GIS и сохраняет их в `.txt` файл. Каждый отзыв записывается с новой строки.

## Как использовать

1. Установить Python 3.
2. Указать публичный API-ключ в `reviews.py`:

```python
API_KEY = "YOUR_API_KEY"
```

3. Запустить скрипт:

```bash
python reviews.py
```

4. Ввести ID компании:

```text
Введите ID компании: 123456789
```

После завершения работы рядом со скриптом появится файл:

```text
123456789.txt
```

В нём будут сохранены тексты найденных отзывов.

## Возможности

* получение отзывов организации;
* автоматическая загрузка отзывов частями;
* обработка HTTP-ошибок;
* удаление переносов строк из отзывов;
* сохранение результатов в текстовый файл.

## Требования

* Python 3
* Публичный API-ключ 2GIS

## Примечание

Проект создан для личного использования и изучения работы с API на Python.
